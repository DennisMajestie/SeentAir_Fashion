# 16. Analytics & Management Dashboard

## Goal

Management should see the important business information from one place, without needing to be at the factory.

## Dashboard data points

- Total sales
- Revenue
- Profit/loss
- Best-selling products
- Slow-moving products
- Low-stock products
- Production status
- Inventory status
- Product profitability
- Sales by channel
- Marketing/source performance
- Partner/investor information (where permitted — see `17-Partners-Investors.md` for access boundaries)

## Data/entities implied

This is primarily a reporting/aggregation layer over the entities defined in files 02, 03, 04, 08, 11, 12, 14, 15. No new core entities, but plan for a dashboard/reporting service that can query across all of them.
